使用说明

库存工作台处理的是本次导入到应用临时空间的 Excel 副本。上传、清除总计行和清空会话均不会改动电脑中的原始文件。

开始前：Excel 源表要求

仅支持 .xlsx。表头、列数和顺序必须完全一致，依次为：

物料编码、物料名称、规格型号、仓库名称、批号、库存主单位、库存量(主单位)、库存状态、库存组织、数量(箱)。

  • 商品以“物料编码 + 物料名称”识别；批号和库存状态不会参与商品识别。
  • 库存量(主单位)和数量(箱)不能为空，且必须为数字。
  • 同一商品、同一仓库出现不同规格时，会被视为源数据异常，需先修正后才能导出。
  • 相同名称和规格对应多个物料编码时，应用会提醒核对；确认继续后会按多行保留。

库存对比

  1. 填写本次对比的品牌名称。
  2. 分别选择或拖入上周和本周的库存 Excel；文件名可以不同。
  3. 上传后如发现末行总计，可点击“清除总计行”。
  4. 点击“生成对比结果”，先处理页面提示的异常或核对项。
  5. 核对预览中的新增、删除、库存增减和同比变化后，导出独立对比表。

库存汇总

  1. 选择或拖入一个或多个品牌 Excel；文件名将作为初始品牌名称。
  2. 可继续添加文件、修改品牌名称、删除品牌文件，或拖动品牌行调整总表中的品牌顺序。
  3. 逐个检查校验结果；发现末行总计时，可在对应品牌行点击“清除”。
  4. 完成德清仓映射后点击“生成汇总表”；未配置品牌可确认继续，此时该品牌的德清仓数量留空。
  5. 核对总表预览后，导出完整汇总表。

德清仓映射

进入“德清仓映射”，为每个品牌选择一个源仓库名称。该仓库在总表中统一归入首组“德清仓”列；其他仓库按源表名称原样展示。不同品牌的同名非德清仓会汇入同一仓库列。

清除总计行

仅当最后一个非空行的物料编码或物料名称包含“总计”或“合计”时，才显示清除操作。点击后会删除应用临时副本中的整行，页面会标记“已清除末行总计”和原始行号；本地原文件不受影响。

导出记录与设置

“导出记录”会保留本机已生成文件，可按类型或名称搜索，并支持重新导出和打开所在文件夹。在“设置”中可修改默认导出路径，以及对比表、汇总表的文件命名格式。

清空与异常处理

“清空文件与结果”只清理当前页面的导入文件、临时副本和预览结果，不会删除原始 Excel、已保存映射、导出设置或导出记录。对比同比按 (本周 - 上周) / |上周| 计算；上周为 0 时显示 -。
