# 库存工作台 v1.1.0

## 本次更新

- "库存对比"正式更名为"单品牌库存对比"。
- 单品牌库存对比改用主单位环比变化，移除箱数同比；上周和本周主单位统一保留两位小数。
- 库存汇总删除品牌文件时新增二次确认。
- 新增"汇总对比"：可上传上周与本周两张库存汇总表，按合计主单位计算环比，并标记新增物料。
- 优化末行总计识别，可识别"总计"、"合计"、"小计"，并避免误清正常商品。
- 设置页新增可选诊断日志，便于排查上传、生成、导出与错误问题。
- 新增"特殊品牌拆分"：自动按"品牌名-仓库名"拆分文件，保留原表字段和样式，并将仓库名称改为短仓名。
- 支持 Python 3.14 打包环境的 Excel 上传，提升安装包的兼容性。

## 使用说明

- 特殊品牌拆分仅支持单工作表 `.xlsx` 文件。
- 仓库名称必须统一为 `品牌名-仓库名` 格式；若存在未带连字符的数据行，软件会停止拆分并提示行号，避免遗漏数据。
