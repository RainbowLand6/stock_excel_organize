# 库存工作台 v1.2.1

## Release title

`v1.2.1 - 汇总对比与导出命名优化`

## Release notes

### 汇总对比

- 汇总对比导出改为以本周库存汇总表为基础，保留原有表头、仓库列、合计列和格式。
- 在合计列后新增“同比”和“备注”两列。
- 本周新增的商品会在备注列标记为“新增物料”。

### 特殊品牌拆分

- 上传后仅在末行识别到“总计”“合计”或“小计”时显示“清除总计行”。
- “清空文件与结果”调整到“开始拆分”按钮左侧，操作顺序更直观。

### 设置

- 设置页统一管理单品牌库存对比、库存汇总、汇总对比和特殊品牌拆分四类导出文件命名规则。
- 旧版本配置会自动补齐新增命名规则。
