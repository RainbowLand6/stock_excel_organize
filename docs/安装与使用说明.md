# 库存工作台使用文档

## 1. 软件用途

库存工作台用于处理各品牌的库存 Excel 文件，提供两项核心工作：

- **单品牌库存对比**：比较同一品牌上周与本周的库存，识别新增、删除及库存数量变化。
- **库存汇总**：将多个品牌的库存表汇总为一张总表，可按“品牌 + 源仓库名称”把仓库归入指定的对应仓库名称。
- **汇总对比**：比较本软件导出的两张库存汇总表，基于合计主单位计算环比变化。
- **特殊品牌拆分**：将仓库名称为“品牌名-仓库名”的合并库存表拆分为多个品牌文件。

软件会将对比表和汇总表分别导出为独立的 `.xlsx` 文件，并保留导出记录。

## 2. 安装与启动

1. 双击安装包 `库存工作台-安装包-1.0.0.exe`。
2. 在安装向导中选择安装位置，完成安装。
3. 从桌面快捷方式或开始菜单中的“库存工作台”启动软件。

首次运行时，Windows 可能提示安全保护。确认安装包来自可信来源后，选择“仍要运行”或继续安装即可。

## 3. 使用前准备

### 3.1 支持的文件

- 仅支持 `.xlsx` 格式的 Excel 文件。
- 一个品牌对应一个库存文件。
- 在库存汇总中，文件名默认作为品牌名称。例如 `品牌A.xlsx` 会识别为“品牌A”。

### 3.2 源库存表列要求

源库存表第一行必须包含以下列，并且列名、列顺序必须完全一致：

| 顺序 | 列名 |
| --- | --- |
| 1 | 物料编码 |
| 2 | 物料名称 |
| 3 | 规格型号 |
| 4 | 仓库名称 |
| 5 | 批号 |
| 6 | 库存主单位 |
| 7 | 库存量(主单位) |
| 8 | 库存状态 |
| 9 | 库存组织 |
| 10 | 数量(箱) |

注意事项：

- `库存状态` 必须位于 `库存量(主单位)` 和 `库存组织` 之间。
- `批号`会保留在源数据中，但不会作为商品识别或比较依据。
- `库存量(主单位)` 和 `数量(箱)` 不能为空，且必须为有效数字。
- 每一行必须填写物料编码、物料名称、规格型号和仓库名称。

## 4. 首次设置

打开左侧的 **设置** 页面，先确认以下内容：

1. **默认导出路径**：选择一个已经存在、并且有写入权限的文件夹。
2. **对比表命名**：默认可使用 `{品牌}`、`{本周日期}`、`{生成日期}`。
3. **汇总表命名**：默认可使用 `{生成日期}`。
4. **诊断日志**：需要排错时可开启；软件会在本机应用数据目录的 `logs\inventory-workbench.log` 记录上传、生成、导出与错误信息。
5. 点击 **保存设置**。

导出路径不能设置在软件安装目录内。建议设置到业务资料目录，例如“文档\库存导出”。

## 5. 单品牌库存对比

适用于同一品牌的上周库存与本周库存比较。

### 操作步骤

1. 打开左侧的 **单品牌库存对比** 页面。
2. 输入本次对比使用的品牌名称。
3. 分别上传上周库存文件和本周库存文件。可点击上传区域选择文件，也可以将 `.xlsx` 文件拖入对应区域。
4. 点击 **生成对比结果**。
5. 查看页面中的校验结果和对比预览。
6. 若出现需要人工确认的提示，核对后勾选确认并继续。
7. 点击 **导出对比表**。

### 对比规则

- 商品识别依据为：**物料编码 + 物料名称 + 仓库名称**。
- 规格型号不同的同一商品仓库记录会被视为异常，需要先修正源数据后才能导出。
- 结果会显示上周、本周、变化值、环比变化和变动类型；环比变化位于变动类型前。
- 上周主单位数和本周主单位数均保留两位小数，采用四舍五入。
- 环比变化按百分比显示，保留两位小数，采用四舍五入；箱数不再计算环比变化。

### 常见的变动类型

- **新增商品**：本周存在、上周不存在。
- **删除商品**：上周存在、本周不存在。
- **库存增加**：本周数量高于上周。
- **库存减少**：本周数量低于上周。
- **无变化**：上周与本周数量一致。

### 清空本次对比

点击 **清空文件与结果** 会清除当前页面已选择的文件和本次对比结果，不会删除已经导出的 Excel 文件。

## 6. 库存汇总

适用于将多个品牌的库存文件汇总为一张总表。

### 导入品牌文件

1. 打开左侧的 **库存汇总** 页面。
2. 点击“添加品牌文件”区域选择一个或多个文件，也可以直接拖入多个 `.xlsx` 文件。
3. 后续可继续选择或拖入文件，软件会**增量添加**，不会覆盖已经导入的品牌文件。
4. 同一品牌不能重复导入。如需重新导入，请先删除原品牌文件。

### 调整品牌顺序

文件列表中每个品牌行左侧有拖拽图标。拖动品牌行可以调整顺序，最终的总表会按照页面上的品牌顺序输出。

### 修改品牌名称

1. 点击品牌行右侧的铅笔图标。
2. 在“修改品牌名称”窗口中输入新名称。
3. 点击 **保存修改**，或按 Enter 保存。

修改后的名称会用于当前汇总预览和最终导出；**不会自动修改仓库映射**。请按新名称在“仓库映射”页面检查或新增对应设置。

### 删除品牌文件

点击品牌行右侧的删除图标后，软件会显示确认窗口。确认后才会移除本次汇总中的品牌文件和应用临时副本；不会删除电脑中的原始 Excel 文件。删除后需重新生成汇总预览。

### 生成与导出总表

1. 确认品牌文件、排序和校验结果无误。
2. 如需调整仓库归属，先完成仓库映射设置；未设置映射的仓库会按原名称汇总。
3. 点击 **生成汇总表**。
4. 若系统提示存在未命中的仓库映射，可核对配置后确认继续生成；未命中的配置不会影响本次文件按原仓库名称汇总。
5. 点击 **导出汇总表**。

### 清除末行总计

导入后，软件会忽略底部空白行，并检查最后一个有内容的数据行的所有列。只要其中包含“总计”“合计”或“小计”，就会显示清除操作。清除只作用于应用临时副本，不会修改原始 Excel 文件。

## 7. 汇总对比

1. 打开左侧的 **汇总对比** 页面。
2. 分别上传上周和本周由本软件导出的库存汇总表。
3. 点击 **生成汇总对比**。
4. 软件以品牌、物料名称和规格匹配记录，读取每行“合计”中的主单位数量，输出上周合计、本周合计、合计变化值和环比变化。
5. 本周存在而上周不存在的记录，会在备注中显示“新增物料”。确认预览后可导出对比表。

上周合计为 0 时，环比变化显示为 `-`。

## 8. 特殊品牌拆分

1. 打开左侧的 **特殊品牌拆分** 页面，上传一张合并库存表。
2. 软件自动识别“仓库名称”列。每条数据的仓库名称必须为 `品牌名-仓库名`，例如 `品牌甲-上海仓`。
3. 如页面提示末行“总计”“合计”或“小计”，可先点击 **清除总计行**；操作只影响应用临时副本。
4. 点击 **开始拆分** 后，软件会生成 `品牌甲_品牌拆分_生成日期.xlsx`、`品牌乙_品牌拆分_生成日期.xlsx` 等独立文件；每个文件保留源表全部列、表头与样式，仓库名称改为 `上海仓`、`广州仓` 等去除品牌前缀后的值。
5. 可在每条拆分结果右侧点击下载按钮；点击 **清空文件与结果** 会清理本次上传和页面结果，不会删除已导出的文件或导出记录。

同一品牌可包含多个仓库。若任一数据行的仓库名称不含半角连字符 `-`，软件会停止拆分并提示行号，避免遗漏数据。

汇总表规则：

- “德清仓”固定为第一组仓库列。
- 除德清仓外，其他仓库按源表中的原仓库名称展示。
- 不同品牌存在同名仓库时，使用同一列展示，但各品牌数据仍按品牌分组，不会混在同一商品行中。
- 总表不展示物料编码。
- 总表按“品牌、序号、名称、规格”展示，并在最后保留合计两列：主单位合计和箱数合计。
- 箱数及箱数合计均保留两位小数，采用四舍五入。

### 清空本次汇总

点击 **清空文件与结果** 会移除当前汇总会话中所有已导入的品牌文件和结果预览，不会删除已经导出的 Excel 文件，也不会删除已保存的仓库映射。

## 9. 仓库映射

每条映射由“品牌 + 源仓库名称 + 对应仓库名称”组成。同一品牌可以设置多个源仓库；多个源仓库也可以映射至同一个对应仓库并自动合计。新增和编辑时，对应仓库名称默认填入“德清仓”，可按需要修改。

### 设置步骤

1. 打开左侧的 **仓库映射** 页面，点击右上角 **新增映射**。
2. 在“品牌”中输入或选择已导入品牌。
3. 输入或选择该品牌源表中的“源仓库名称”。
4. 输入“对应仓库名称”，然后保存。
5. 可使用每行右侧的编辑按钮修改三项内容；删除时软件会再次确认。

生成汇总表时，该品牌中仓库名称与源仓库名称一致的记录会写入对应仓库名称列；未映射仓库保持原名称。若“德清仓”实际出现，会固定显示在第一组仓库列。

### 未命中映射

当以下情况出现时，软件会在生成汇总表前提示：

- 已保存的源仓库名称未在本次导入文件中出现。

确认继续即可；未命中的配置不会阻止汇总，本次文件中的仓库仍会按已有映射或原仓库名称正常汇总。

## 10. 校验提示与处理方式

软件会在页面中显示具体的文件名、工作表和出错行号，便于直接回到源 Excel 修正。

| 提示情况 | 处理方式 |
| --- | --- |
| 列名或列顺序不一致 | 按第 3.2 节调整表头，尤其确认已加入“库存状态”列。 |
| 主单位数量或箱数为空 | 回到提示的文件和行号，补充数值后重新导入。 |
| 主单位数量或箱数不是数字 | 将单元格改为有效数字，不要填写文字、横线或无效符号。 |
| 必填字段为空 | 补充物料编码、物料名称、规格型号或仓库名称。 |
| 末行“总计”“合计”或“小计” | 软件会自动跳过该行，页面也会提供“清除总计行”操作；不需要将总计行当作物料数据补填。 |
| 同一商品、同一仓库出现不同规格 | 视为源数据异常，需在源表中核对并修正后再导出。 |
| 相同名称和规格对应多个物料编码 | 系统会提示核对；确认后可继续生成，结果会按多行保留。 |
| 同一品牌重复导入 | 先删除汇总列表中的旧文件，再重新导入。 |

## 11. 导出记录

打开左侧的 **导出记录** 页面，可以：

- 查看已导出的单品牌库存对比表和库存汇总表。
- 按品牌、文件名或类型搜索记录。
- 使用“打开文件夹”按钮定位导出文件所在目录。

## 12. 数据保存与卸载说明

- 仓库映射、导出设置和导出记录保存在当前 Windows 用户的应用数据目录，不保存在软件安装目录。
- 卸载软件不会主动删除已经导出的 Excel 文件，也不会主动删除用户配置数据。
- 更换电脑时，建议保留源库存表和已导出的结果文件；新电脑上需要重新安装软件并重新设置导出路径、仓库映射。

## 13. 日常建议流程

每周可按以下顺序操作：

1. 在“设置”确认导出路径。
2. 在“单品牌库存对比”导入上周和本周的同品牌文件，核对并导出对比表。
3. 在“库存汇总”逐步导入需要汇总的品牌文件。
4. 调整品牌顺序，检查或补充仓库映射。
5. 生成汇总预览，处理校验提示后导出总表。
6. 在“导出记录”确认文件已生成并打开所在文件夹。
