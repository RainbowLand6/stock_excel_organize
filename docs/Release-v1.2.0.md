# 库存工作台 v1.2.0

## Release title

`v1.2.0 - 仓库映射与特殊品牌拆分完善`

## Release notes

### 新增

- 新增汇总对比：上传上周、本周两张库存汇总表，按合计主单位计算环比；本周新增商品在备注中标记“新增物料”。
- 新增特殊品牌拆分：识别“品牌名-仓库名”，按品牌导出独立 Excel，并保留原始列、表头与样式。
- 特殊品牌拆分支持下载每条结果、清除末行总计和清空本次文件与结果。
- 设置中可开启诊断日志，并可直接打开日志文件用于排错。

### 优化

- “库存对比”更名为“单品牌库存对比”；主单位同比变化更名为环比变化并移至变动类型前，上周和本周主单位均保留两位小数。
- 汇总对比导出文件命名为 `汇总对比_生成日期.xlsx`；特殊品牌拆分文件命名为 `品牌_品牌拆分_生成日期.xlsx`。
- 末行精确为“总计”“合计”或“小计”时会自动忽略，避免被误报为必填字段为空；页面仍可按需清除该临时行。
- 导出记录移除“重新导出”，保留文件夹定位功能。

### 仓库映射

- “德清仓映射”升级为“仓库映射”。
- 支持“品牌 + 源仓库名称 -> 对应仓库名称”的多条映射；对应仓库默认“德清仓”，可编辑。
- 新增映射位于页面右上角；映射支持编辑和删除，删除需要二次确认。
- 未配置映射的仓库保持原名称参与汇总；未命中的旧配置仅提示核对，不影响本次汇总。
